# Visão geral

O UFSM-MDT é um projeto open source em desenvolvimento para facilitar a criação, organização, formatação e futura validação de trabalhos acadêmicos baseados nas diretrizes do Manual de Dissertações e Teses (MDT) da Universidade Federal de Santa Maria.

## Problema

A preparação de trabalhos acadêmicos envolve tarefas repetitivas: elementos pré-textuais, títulos, figuras, tabelas, referências e conferências antes da entrega.

## Escopo inicial

1. Organizar uma base LaTeX compatível com o fluxo acadêmico da UFSM.
2. Simplificar a configuração dos dados do trabalho.
3. Documentar a estrutura esperada.
4. Criar exemplos mínimos.
5. Preparar a base para um validador automatizado.
6. Preparar compilação automatizada com GitHub Actions.

O projeto não substitui orientação docente nem declara aprovação institucional por conta própria.
