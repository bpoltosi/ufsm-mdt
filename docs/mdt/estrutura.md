# Estrutura documental — MDT UFSM 2021

## Estrutura geral

A MDT define a estrutura física dos trabalhos em elementos externos e internos. Os elementos internos são divididos em:

1. pré-textuais;
2. textuais;
3. pós-textuais.

A MDT registra que os pré-textuais são contabilizados no total de páginas, mas não recebem numeração e não aparecem no sumário. As páginas que não são pré-textuais recebem paginação, incluindo os elementos pós-textuais.

## Pré-textuais

O sumário da MDT organiza os elementos principais da seguinte forma:

### Externos
- capa;
- lombada.

### Internos
- folha de rosto;
- ficha catalográfica;
- errata;
- folha de aprovação;
- dedicatória;
- agradecimentos;
- epígrafe;
- resumo em língua vernácula;
- resumo em língua estrangeira;
- listas;
- sumário.

A MDT marca individualmente itens como obrigatórios ou opcionais.

## Textuais

A MDT possui um capítulo específico para elementos textuais, incluindo:

- numeração progressiva de seções;
- citações;
- equações e fórmulas;
- ilustrações;
- quadros;
- tabelas;
- artigos integrados no desenvolvimento;
- considerações finais.

Isso é importante para o projeto porque o conteúdo textual não pode ser modelado apenas como uma lista rígida de "Introdução → Desenvolvimento → Conclusão": a MDT permite estruturas de desenvolvimento que precisam ser representadas pelo modelo interno.

## Pós-textuais

A MDT apresenta:

- apêndice;
- anexo;
- referências.

As referências possuem um capítulo próprio, bastante extenso, com regras de apresentação e diferentes tipologias bibliográficas.

## Idioma

A MDT estabelece o português como idioma adotado pela UFSM para trabalhos de conclusão de curso de graduação e pós-graduação, mas admite outros idiomas quando isso estiver previsto pelo Regimento do Curso/Programa ou relacionado à área/política de internacionalização.

Quando o trabalho é redigido em outro idioma, o manual determina que a versão final contenha obrigatoriamente título, resumo e palavras-chave em português.

## Elementos obrigatórios para entrega

Na seção sobre entrega da versão final, a MDT destaca como pré-textuais obrigatórios, entre outros:

- folha de rosto;
- ficha catalográfica;
- folha de aprovação;
- resumo em língua vernácula;
- resumo em língua estrangeira;
- sumário.

Também determina título, resumo e palavras-chave em português e inglês para a inserção da versão final no Manancial.

## Implicações para o sistema

O modelo interno deve separar:

```
external
pretextual
textual
posttextual
```

E dentro dos textuais deve permitir:

- capítulos/seções arbitrários;
- citações;
- equações;
- figuras/ilustrações;
- quadros;
- tabelas;
- artigos integrados;
- considerações finais.
