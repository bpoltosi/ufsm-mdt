## Regra de manutenção

Antes de uma mudança estrutural no template, gerador, validador, perfis de trabalho ou fluxo de build, verificar as decisões registradas em `decisoes.md` e atualizar a documentação quando a decisão mudar.

As issues do GitHub representam as unidades de trabalho. Cada issue deve permanecer ligada a um bloco de construção e aos documentos que definem seus critérios.
